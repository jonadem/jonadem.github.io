# libreGuess

A local multiplayer guessing game for one shared phone, tablet, or computer. Open `index.html` in a browser to play. No accounts, dependencies, or internet connection are required for button or keyboard controls.

1. Choose one of four decks and set a 30-, 60-, or 90-second round.
2. One player holds the screen at their forehead, facing the other players.
3. Friends give clues without saying the prompt. For silent charades, choose **Act It Out** and mime each prompt.
4. Select **Got it** or press the right arrow for a correct guess. Select **Pass** or press the left arrow to skip. Rotate the guesser each round.

To play hands-free, enable tilt on the ready screen using a phone and browser with motion support. Tilt needs a secure context, typically HTTPS or localhost. Hold the phone upright when starting, tilt down for a correct guess or up to pass, and return upright between prompts.

For local web development, run `python3 -m http.server 8000` in this directory and visit `http://localhost:8000`.

## Jouer en français

Ouvrez [fr.html](fr.html) dans votre navigateur ou sélectionnez **Français** depuis la version anglaise. Choisissez une catégorie et la durée de la manche. Une personne tient le téléphone contre son front et devine les mots grâce aux indices des autres joueurs. Choisissez **À mimer** pour jouer sans parler.

Touchez **Trouvé** ou appuyez sur la flèche droite pour valider, et utilisez **Passer** ou la flèche gauche pour passer. Pour jouer sans les mains sur un téléphone compatible, activez les gestes sur l’écran de préparation. Inclinez le téléphone vers le bas pour valider ou vers le haut pour passer, puis redressez-le entre les mots.
